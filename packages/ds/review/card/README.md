# Card review evidence

**Scope:** provisional `wk-card` implementation for issue #12; not shared
production promotion.

**Source:** branch `copilot/issue-12-card`, based on commit
`27e552f1d8ceb7de91e0c67b12dae83248608bca`. The PR and CI record identify
the final reviewed head.

**Synthetic evidence:** Chromium 156.0.8078.4, Node 22.16.0, Storybook
10.6.3, Vite 7.3.7 and Playwright 1.64.1. The fixture data and images are
synthetic.

| Story ID                                          | Review coverage                                                                                  |
| ------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| `components-card--composition-current-slice`      | Actual Card, TextField, Select, form buttons and mode switch together; desktop/phone, light/dark |
| `components-card--body-only`                      | Body-only composition                                                                            |
| `components-card--heading-and-body`               | Native heading and body                                                                          |
| `components-card--actions`                        | Independent action controls and focus                                                            |
| `components-card--long-content-and-narrow-reflow` | Long heading/body/actions and narrow reflow                                                      |

**Automated checks:** `pnpm test`, `pnpm lint`, `pnpm typecheck`,
`pnpm check:boundaries` and `pnpm build-storybook`. The Card Chromium review
gate checks 16px padding, 12px section gaps, occupied slots, Card/page
horizontal overflow and browser errors. Story play tests check native heading
semantics, absence of Card role/tab stop, action focus, theme/mode/wireframe
geometry and theme scoping.

**Not run:** manual assistive-technology, real-device, zoom/contrast,
Firefox/WebKit or React/Angular checks. Chromium and automated accessibility
checks do not certify WCAG conformance. Production-use evidence and a separate
promotion approval are absent; no production adoption is claimed. Migration
automation versus notification remains an open governance decision.
